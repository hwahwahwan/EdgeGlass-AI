# EdgeGlass-AI 배터리와 DFR1026 호환성 조사

조사일: 2026-10-26
대상: K230D-Zero + OV5647 + SSD1306 OLED + Wi-Fi/UDP 무선 마우스 기능을 동시에 사용하는 짧은 시연

> 후속 비교 조사와 실제 주문 조합은 [배터리 전원 방식 비교](battery-power-options.md)에 정리했다. 최종 권고는 DFR1026의 충전 기능을 사용하지 않고, 보호 Li-Po를 분리형 500mA 충전기로 충전하는 방식이다.

## 1. 최종 판정

**현재 확인할 수 있는 500~1,000mAh 단셀(3.7V) Li-Po를 DFR1026에 바로 연결해 충전하는 조합은 구매 확정 불가(비추천)이다.**

DFR1026은 단일 리튬 배터리를 5V로 승압하고 충전·방전을 함께 할 수 있는 모듈이므로, 전압과 방전 전력 면에서는 이 프로젝트에 맞는다. 다만 제조사는 충전 전류를 `0~2.1A`로만 명시하며, 사용자가 충전 전류를 낮추는 방법이나 소형 배터리에 맞춰 자동 제한하는 동작을 공개하지 않았다. 따라서 이 수치는 작은 배터리에 안전한 충전 전류가 아니라 **모듈 측 상한**이다.

500/800/1,000mAh 셀에 2.1A가 흐를 수 있다고 보수적으로 보면 각각 4.2C/2.63C/2.1C이다. 제조사 데이터시트에 이 이상의 허용 충전 전류가 명시되지 않은 소형 셀에는 과전류가 될 수 있다. 조사한 국내 판매 후보에는 이 핵심 수치가 공개되어 있지 않다.

**따라서 지금 사야 할 것은 배터리가 아니라, 판매처/제조사로부터 “1S 3.7V, 보호회로 포함, 연속 방전 1A 이상, 허용 충전 전류 2.1A 이상”을 서면으로 확인할 수 있는 배터리와 그 짝 소켓이다.** 해당 확인을 받지 못하면 DFR1026의 충전 기능은 사용하지 말고, 충전 전류를 정할 수 있는 1셀 Li-Po 충전기로 충전해야 한다. 별도 충전기를 추가하는 것은 최소 구성 원칙에는 불리하지만, 이 조건을 충족하지 못할 때 안전상 필요한 대안이다.

## 2. 확인된 DFR1026 사양

다음은 DFRobot의 제품 페이지에 있는 확인된 사실이다.

| 항목 | 확인된 내용 |
| --- | --- |
| 배터리 | 단일 3.7V/만충 4.2V 리튬 배터리용 |
| 충전 입력 | DC 4.6~5.4V, 전형값 5V; 입력 전류 2~3A |
| 충전 | 충전 전류 0~2.1A, 만충 4.2V ±1% |
| 출력 | 5V, 출력 전류 0~2.1A (소개문은 최대 부하 2A) |
| 효율 | 승압 `≤92%`, 충전 `≤91%`, 방전 `≤96%`로 제조사 표기. 최소 보장 효율로 해석하면 안 됨. |
| 보호 | 과전류·과전압·과열·단락 보호를 명시. 역극성 보호나 개별 배터리 보호회로 전체를 대체한다는 명시는 없음. |
| 동시 사용 | 충전 중 출력 사용을 지원. 제조사는 입력과 출력을 함께 활성화해 균형을 유지하라고 안내함. |
| 크기 | 25 × 16mm, 패드 피치 2.54mm, 홀 1mm |

`2.1A`는 배터리의 권장 충전 전류가 아니다. 공식 자료에는 실제 충전 전류가 항상 2.1A인지, 조건에 따라 변하는지, 이를 조절할 수 있는지에 관한 회로도·데이터시트·설정 방법이 없다. 공개 제품 페이지의 Resource에도 회로도/상세 데이터시트는 제공되지 않았다.

### 공식 핀 배치와 기능

공식 핀 배치도에는 여섯 패드가 `OUT-5V`, `GND`, `BAT`, `GND`, `GND`, `VIN`으로 표시된다. `BAT`은 배터리 양극, `OUT-5V`는 5V 출력 양극, `VIN`은 5V 충전 입력 양극이다. 음극/리턴은 모두 GND 패드다. 즉 별도의 `BAT−`, `OUT−`, `VIN−` 패드가 있는 구조가 아니라 공통 GND를 쓴다. 납땜 직전에는 반드시 실제 보드 실크 인쇄와 [공식 핀 배치도](https://dfimg.dfrobot.com/enshop/image/cache3/data/DFR1026/intro/2_0x0.jpg.webp)를 대조한다.

## 3. 배터리별 충전·방전 판단

### 소비 전류와 사용 시간 계산

확인된 측정값은 모든 기능 동시 실행 시 5V에서 약 0.43A이다. 소비 전력은 약 2.15W다. 승압 효율을 제조사가 표기한 92%로 **가정**하면, 3.7V 배터리에서 약 0.63A가 필요하다 (`5 × 0.43 ÷ (3.7 × 0.92)`). 실제 효율, 셀 전압 하강, 피크 전류에 따라 더 짧아질 수 있다.

| 용량 | 계산상 시연 시간 | DFR1026 직결 충전 판단 |
| --- | ---: | --- |
| 500mAh | 약 0.79시간 (47분) | 최대 2.1A 가정 시 4.2C. 허용 충전 전류 확인 전 사용 금지. |
| 800mAh | 약 1.27시간 (76분) | 최대 2.1A 가정 시 2.63C. 허용 충전 전류 확인 전 사용 금지. |
| 1,000mAh | 약 1.58시간 (95분) | 최대 2.1A 가정 시 2.1C. 허용 충전 전류 2.1A 이상 확인 전 사용 금지. |

출력 전류 0.43A는 DFR1026의 2A 정격보다 낮다. 배터리 연속 방전 전류는 계산상 약 0.63A 이상이고, 전원 인가·무선 동작의 변동과 여유를 고려해 **최소 1A 이상**을 명시한 제품을 조건으로 삼는다. 보호회로가 있는 배터리가 바람직하다. DFR1026 보호 기능은 보조 보호이지, 셀 제조사의 허용 충전·방전 한계를 바꾸지 않는다.

TW102050을 선택할 수 있을 만큼의 안전 증빙을 판매처에서 받는 경우에만, 대응 소켓은 Molex 51021 계열의 **1.25mm 2핀**으로 선택한다. 그러나 극성은 제품 사진이나 테스터로 확인한 뒤에만 결선한다. 소켓·전선·케이블의 통상 소매 가격은 판매처·배송비에 따라 달라 총비용을 신뢰성 있게 확정할 수 없다.

배터리까지 포함한 **안전 확정 최소 총비용도 현재는 산정 불가**다. 확인되지 않은 배터리 가격을 합산해 마치 안전한 조합인 것처럼 제시하지 않는다.

## 6. 실제 연결과 납땜 방법

```text
보호회로 포함 1S Li-Po
  + ── 배터리 플러그 ── 대응 소켓 적색선 ── DFR1026 BAT
  - ── 배터리 플러그 ── 대응 소켓 흑색선 ── DFR1026 GND

안정화된 5V USB 전원 ── DFR1026 VIN / GND       (배터리 충전)
DFR1026 OUT-5V / GND ── 5V USB 케이블 ── K230D-Zero USB-C 전원
```

1. 배터리의 커넥터 시리즈·피치·극성을 판매 페이지와 실물 멀티미터로 확인한다. 같은 2핀 커넥터라도 제조사별 극성이 반대일 수 있다.
2. 리드선형 대응 소켓의 적색선을 `BAT`, 흑색선을 인접한 `GND`에 납땜한다. 납땜 전후 BAT-GND 사이 단락이 없는지 확인한다.
3. 출력은 `OUT-5V`와 GND에서 가져온다. USB-C 플러그를 직접 자작하는 대신, 기성 USB-A 수→USB-C 수 케이블을 사용하거나 USB-C 전원용 브레이크아웃의 사양을 확인한다. K230D-Zero에는 5V 전원만 넣고 데이터선은 연결하지 않는다.
4. 충전은 DFR1026의 `VIN`과 GND에 안정된 5V USB 전원을 연결한다. 단, 선택한 배터리의 허용 충전 전류가 2.1A 이상 확인된 경우에만 이 방법을 쓴다. 그렇지 않으면 배터리 사양에 맞춰 전류를 설정할 수 있는 전용 1셀 Li-Po 충전기를 사용한다.
5. 처음에는 K230D-Zero를 연결하지 않고 배터리 전압과 5V 출력 극성을 측정한다. 다음에는 전류 제한 가능한 전원으로 짧게 시험하고, 셀·배선·모듈의 비정상 발열이 없는지 확인한 후 시연에 쓴다.

충전 중 출력 사용은 공식 지원 범위지만, 시연 장비를 연결한 채 장시간 충전 상태로 방치하지 않는다. 충전 중에는 KEY 조작이 동작하지 않는다.

## 7. 해결되지 않은 사항과 구매 전 확인 목록

- DFRobot 공개 자료에는 회로도/상세 데이터시트와 충전 전류 조절 방법이 없다.
- 2.1A가 어떠한 조건에서 실제로 흐르는지, 온도·입력 전원·부하에 따른 값은 확인되지 않았다.
- 조사한 국내 후보의 허용 충전 전류, 연속 방전 전류, 리드 극성, 일부 보호회로·중량 정보는 공개되지 않았다.
- K230D-Zero의 USB-C 입력에 사용할 케이블/브레이크아웃의 5V 전원 역할과 극성은 실제 조립 전 보드 설명서와 테스터로 확인한다.
