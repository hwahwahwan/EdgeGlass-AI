# EdgeGlass-AI 저가형 충전·승압 통합 모듈 조사

조사일: 2026-10-26

## 결론

**1만~2만원에서 바로 주문 가능한 조합 중, 가장 현실적인 저가 후보는 `TP4056+SDB628 Type-C 충전·승압 모듈 + Rayman LYS ICR18350P 보호 배터리`다.** 18350 전용 홀더와 출력 케이블까지 포함한 부품가는 **17,844원**이다(배송비·부가세 처리 비용 제외).

다만 이것은 “조립 후 실제 부하 시험을 통과할 때만 사용”하는 조건부 추천이다. 모듈 출력 한계와 배터리 연속 방전 한계가 모두 1A라서, 5V/0.43A의 현재 평균 부하는 가능 범위지만 Wi-Fi·카메라의 순간 피크까지 데이터시트만으로 보장할 여유는 작다. 조립 뒤 5V 단자 전압과 배터리 전류를 실제 최대 기능 상태에서 측정해, 재부팅·전압 저하·비정상 발열이 없을 때만 시연 장비로 쓴다.

500~1,000mAh **파우치 Li-Po**와 저가 통합 모듈을 안전하게 바로 결합하는 확정 조합은 찾지 못했다. 공개 충·방전 한계가 확인된 파우치 셀은 이 프로젝트의 승압 입력 전류에 여유가 없거나, 모듈의 1~2.1A 충전 전류에 맞지 않았다. 따라서 최저가 조합에는 1A 충전·방전과 보호회로가 명시된 1,000mAh **보호 18350 Li-ion** 셀을 사용한다. 원통형이라 Li-Po보다 장착성은 떨어진다.

## 계산 기준

확인된 측정값은 5V에서 약 0.43A(약 2.15W)다. 85~90% 승압 효율을 **가정**하면 3.7V 배터리 쪽 전류는 약 0.65~0.68A이고, 방전 종료 근처 3.0V에서는 약 0.80~0.84A까지 올라갈 수 있다. 따라서 1A급 배터리와 1A 출력 모듈은 평균 부하에는 맞지만 피크 여유가 크지 않다.

#### 호환성 판정

- 충전: 모듈 1A와 배터리 최대 충전 1A가 일치한다. 1A를 넘기는 어댑터를 쓴다고 배터리 충전 전류가 늘어나는 구조라고 판단하지 않는다.
- 방전: 현재 평균 부하의 추정 배터리 전류 0.65~0.84A는 배터리 1A와 모듈 5V/1A 안에 있다.
- 출력: 모듈 5W/5V 1A는 평균 2.15W보다 크지만, 약 2.3배일 뿐이다. 실제 피크 검증 전에는 안정적 호환으로 확정하지 않는다.
- 보호: 모듈은 저전압 차단을 표기하지만, 배터리 자체 보호회로를 대신하는 근거는 없다. 반드시 위와 같은 보호 배터리를 쓴다.
- 전원 스위치: 모듈의 내장 스위치 여부가 판매 사양에 없다. 별도 스위치를 넣으려면 배터리 양극과 `B+` 사이에 **DC 5V/2A 이상 정격**의 래칭 스위치를 직렬로 넣는다. 스위치가 필요 없다면 추가 구매하지 않는다.

### 3. 제외: IP5306/MH-CD42 + 소형 Li-Po

[MH-CD42 IP5306 계열 모듈](https://item.gmarket.co.kr/Item?goodsCode=4730820492)은 9,220원(무료배송)이고 5V 약 2.1A 출력을 표기해 출력 여유는 좋다. 그러나 [IP5306 데이터시트](https://datasheet.lcsc.com/lcsc/INJOINIC-IP5306_C181692.pdf)는 충전 전류 2.1A급을, 다른 개정판은 1.8A급을 제시한다. 일반 MH-CD42 보드에 이를 500~1,000mAh 셀 수준으로 낮추는 설정 수단은 확인되지 않았다.

예를 들어 보호 500mAh Li-Po는 최대 충전·방전이 보통 0.5A이고, 1,000mAh 소형 셀도 1A 수준인 제품이 많다. 1.8~2.1A 충전은 이 범위를 넘을 수 있으므로 이 조합은 구매 후보에서 제외한다. IP5306의 보호 기능과 출력 전류 표기는 배터리 자체의 허용 충전 전류를 높여 주지 않는다.

## 실제 납땜·충전 방법

```text
18350 배터리 (+) ── 홀더 적색선 ── 모듈 B+
18350 배터리 (-) ── 홀더 흑색선 ── 모듈 B-

모듈 OUT+ ── 잘라낸 USB-A→USB-C 케이블의 적색 VBUS ── K230D-Zero USB-C
모듈 OUT- ── 잘라낸 케이블의 흑색 GND ──────────────── K230D-Zero USB-C

안정된 5V USB-A 충전기 ── A→C 케이블 ── 모듈 Type-C 충전 입력
```

1. 홀더 적색/흑색 리드를 각각 `B+`/`B−`에 납땜한다. 배터리를 끼우기 전 B+와 B−가 단락되지 않았는지 확인한다.
2. 출력 케이블은 USB-A 쪽을 잘라 적색(VBUS)·흑색(GND)만 `OUT+`/`OUT−`에 납땜한다. 흰색·녹색 데이터선과 실드는 서로 닿지 않게 절연한다.
3. 배터리를 넣기 전 충전 포트에 5V를 연결해 출력 패드의 전압과 극성을 측정한다. 다음으로 배터리를 넣고 5V 출력이 유지되는지 확인한다.
4. K230D-Zero를 연결한 첫 시험에서는 Wi-Fi·카메라·OLED를 모두 켜고 최소 10분간 5V 전압, 재부팅 여부, 모듈·배터리·배선 온도를 확인한다. 4.75V 아래 전압 강하, 재부팅, 뜨거운 부품이 있으면 사용을 중단한다.
5. 충전 시에는 모듈 Type-C 입력에 **일반 5V USB-A→USB-C 케이블**을 사용한다. 판매 페이지에서 C-to-C 충전 호환을 보장하지 않았으므로 USB-C PD 충전기와 C-to-C 케이블 조합은 쓰지 않는다. 충전 중 장비 사용·방치는 하지 않는다.

## 확인되지 않은 위험과 주문 전 점검

- 두 1A급 조합 모두 실제 Wi-Fi 순간 피크와 저전압 배터리 상태에서의 안정성 시험이 필요하다. 이 시험 전에는 장시간·무인 사용을 하지 않는다.
- SDB628과 SZH-CH039 판매 자료에는 충전 중 부하를 안정적으로 유지하는 power-path 동작이 확인되지 않았다. 전원을 끄고 충전하는 방식으로 사용한다.
- 18350 전용 홀더를 사용한다. 일반 18650 홀더는 셀 길이가 달라 쓰지 않는다.
- 배터리 라벨·보호회로 상태·극성을 실물로 확인한다. 손상·팽창·피복 손상 셀은 사용하지 않는다.
