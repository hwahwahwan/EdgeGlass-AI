# EdgeGlass-AI 배터리 조립 매뉴얼

확인일: 2026-10-26  
적용 범위: DFR1026을 5 V 승압 전원으로만 사용하고, SZH-EK026으로 배터리를 분리 충전하는 조건부 시제품

> **시작 조건:** [구매 체크리스트](battery-purchase-checklist.md)의 배터리 하네스·출력 하네스 검증 게이트를 모두 통과하기 전에는 이 매뉴얼의 납땜 단계를 시작하지 않는다. 현재 제시된 `53047-0210` 단독 헤더는 1 A 공개 정격·PCB 장착용이므로 사용하지 않는다.

## 1. 확인된 배선 구조

```text
시연 중 (TP4056은 미연결)
보호 Li-Po ── [전류 정격 확인된 탈착 하네스] ── DFR1026 BAT / GND
DFR1026 OUT-5V / 출력 GND ── USB-A 암 출력 하네스 ── 3 A USB-A→USB-C 케이블 ── K230D-Zero

충전 중 (DFR1026과 K230은 미연결)
보호 Li-Po ── [전류 정격 확인된 탈착 하네스] ── SZH-EK026 BAT+ / BAT−
5 V USB 전원 ── Micro-USB 케이블 ── SZH-EK026
```

배터리는 시연용 DFR1026 하네스 또는 충전용 TP4056 하네스 중 **하나에만** 연결한다. 두 하네스나 DFR1026 충전 입력을 동시에 연결하지 않는다. 셀 탭·보호회로에는 납땜하지 않는다.

## 2. DFR1026 핀과 연결 위치

DFRobot 공식 핀 배치의 후면 패드를 아래에서 위로 읽으면 다음과 같다.

| 패드 | 공식 표기 | 이 조립에서의 처리 |
| ---: | --- | --- |
| 1 | `VIN` | 사용 안 함. 절연·개방. |
| 2 | `GND` (VIN−) | 사용 안 함. 절연·개방. |
| 3 | `GND` (BAT−) | 검증된 배터리 하네스의 **측정 확인된 음극**. |
| 4 | `BAT` | 검증된 배터리 하네스의 **측정 확인된 양극**. |
| 5 | `GND` (OUT−) | USB-A 출력 하네스의 **도통 확인된 GND**. |
| 6 | `OUT-5V` | USB-A 출력 하네스의 **도통 확인된 VBUS**. |
| 7 | `KEY` | 평소 미연결. 출력 제어가 필요할 때만 순간누름 버튼을 패드 5와 연결. |

공식 제품 자료는 출력 5 V/0~2.1 A, 승압 효율 최대 92%, 25×16 mm, 과전류·과전압·과온·단락 보호를 제시한다. DFR1026의 출력 능력이 K230D-Zero 실제 순간 피크 통과를 보증하는 것은 아니다.

- [DFRobot DFR1026 공식 제품·핀 배치](https://www.dfrobot.com/product-2632.html)
- [K230D-Zero 공식 사양](https://www.kendryte.com/k230_canmv/en/main/userguide/boards/canmv_k230d.html): USB-C 5 V/2 A 입력

## 3. 실물 식별

### 배터리

1. 팩 라벨이 `DTP103450`, 3.7 V, 1,800 mAh인지 확인한다.
2. 보호회로와 피복에 눌림·팽창·찢김·냄새가 없는지 확인한다.
3. 판매자 문서와 출고 커넥터 품번·리드 AWG가 일치하는지 확인한다.
4. 커넥터의 두 단자 전압을 멀티미터로 측정하여 실제 양극·음극을 표시한다. **핀 번호, 적색/흑색 색상, 유사 제품 사진만으로 극성을 정하지 않는다.**

### SZH-EK026

Micro-USB 포트와 `IN+`, `IN−`, `BAT+`, `BAT−` 표기를 확인한다. 이 모델은 충전기이며 출력(power-path) 단자가 아니다. 충전 중에는 DFR1026 또는 K230D-Zero를 연결하지 않는다.

### USB-A 출력 하네스

K230D-Zero는 USB-C 싱크이므로, USB-C 수전용 브레이크아웃에 전선 두 가닥을 임의로 연결하지 않는다. USB-A 암 단자가 달린 검증 하네스와 USB-A→USB-C 케이블을 사용한다. 납땜 전 USB-A 단자의 VBUS와 GND를 멀티미터 도통으로 식별한다.

## 4. TP4056 충전전류를 0.78 A로 변경

### 필요한 부품·공구

- SZH-EK026
- 1.5 kΩ 0603(1608 metric) 저항, `AR03BTC1501`
- 온도조절 인두와 미세 팁 또는 열풍기, 핀셋, 플럭스, 납제거 심지
- 확대경, 멀티미터

### 절차

1. USB 전원과 배터리를 완전히 분리한다.
2. TP4056 옆의 `122` 표기 RPROG 저항을 찾는다. 수령품의 저항 패키지가 **0603인지** 확대경·실측으로 확인한다. 다르면 중단한다.
3. 플럭스를 바르고 핀셋과 열풍 또는 미세 팁으로 `122`를 제거한다. 주변 TP4056 핀을 가열하지 않는다.
4. 1.5 kΩ 0603 저항을 같은 두 패드에 납땜한다.
5. 저항값을 측정해 약 1.5 kΩ이고 인접 패드와 단락되지 않았는지 확인한다.
6. 배터리만 연결하고 5 V Micro-USB 전원을 연결한다. USB 전력계 또는 전류 측정으로 초기 충전전류가 **0.78 A 이하**임을 확인한다. 모듈이 과열되거나 전류가 기준을 넘으면 즉시 분리한다.

판매처 설정표는 1.5 kΩ에서 약 780 mA를 제시한다. 이 값은 DTP103450의 0.5C 표준 충전 0.9 A보다 낮다. TP4056은 선형 충전기이므로 충전 중 뜨거워질 수 있다. 불연성 표면에서, 사람이 지켜보는 동안만 충전한다.

## 5. 배터리 충전 하네스 조립

이 단계는 배터리 공급처가 커넥터·리드의 1.8 A 연속 정격을 확인하고, 이에 맞는 **두 개의 탈착 하네스**를 정한 뒤에만 한다.

1. 충전 하네스의 측정 확인된 양극을 `BAT+`, 음극을 `BAT−`에 납땜한다.
2. 각 납땜부에 2 mm 열수축튜브를 씌우고 수축시킨다.
3. 하네스가 TP4056 패드에 힘을 주지 않도록 케이블타이·케이스 고정점으로 인장완화를 만든다.
4. 배터리를 연결하기 전 BAT+와 BAT− 사이 단락이 없는지 확인한다.
5. 배터리를 연결하고, Micro-USB로 안정화 5 V를 공급한다. 충전 LED와 전류를 확인한다.

## 6. DFR1026 승압 출력 조립

1. 22 AWG 적·흑 연선을 각각 **15 cm 이하**로 자른다. 배터리 및 출력 하네스의 전류 정격이 확인되지 않았다면 이 단계는 진행하지 않는다.
2. DFR1026 패드 6 `OUT-5V`에 출력 하네스의 도통 확인된 VBUS, 패드 5 `GND`에 GND를 납땜한다.
3. 패드 4 `BAT`에는 배터리 하네스의 측정 확인된 양극, 패드 3 `GND`에는 음극을 납땜한다.
4. 패드 1 `VIN`·2 `GND`에는 아무것도 연결하지 않는다. 납땜 잔여물이 없도록 확인한다.
5. 모든 패드에 열수축튜브·캡톤테이프를 적용하고, 기판과 전선이 케이스 안에서 움직이지 않게 고정한다.
6. USB-A 암 출력 하네스에 3 A USB-A→USB-C 케이블을 연결하고 K230D-Zero USB-C에 연결한다. USB-C 플러그에 전선을 직접 납땜하지 않는다.

## 7. 최초 전원 투입 전 체크리스트

- [ ] 배터리 피복, 보호회로, 리드, 커넥터에 손상이 없다.
- [ ] 배터리 양극·음극은 멀티미터로 확인했고 라벨을 붙였다.
- [ ] TP4056의 RPROG는 1.5 kΩ이며 단락이 없다.
- [ ] 충전 중에는 배터리가 DFR1026·K230에서 완전히 분리된다.
- [ ] DFR1026 `VIN`/입력 GND에는 연결이 없다.
- [ ] DFR1026 패드 4/3은 BAT+/BAT−, 패드 6/5는 OUT+/OUT−로 도통 확인했다.
- [ ] DFR1026 출력과 GND 사이에 전원 미인가 상태 단락이 없다.
- [ ] DFR1026 출력 전압·극성은 K230 연결 전에 측정한다.
- [ ] 케이스 안에서 납땜부·배터리·금속 프레임이 닿지 않으며, 케이블 인장완화가 있다.

## 8. 시험 순서와 합격 기준

### 충전 시험

1. 배터리를 충전 하네스에만 연결한다.
2. Micro-USB 5 V 전원을 연결하고 충전전류가 0.78 A 이하인지 확인한다.
3. 충전기·배터리의 비정상 발열, 냄새, 팽창이 없을 때만 충전을 계속한다.
4. 충전 중에는 시연 회로나 DFR1026을 연결하지 않는다.

### 무부하 출력 시험

1. 충전이 끝난 배터리를 DFR1026 시연 하네스에만 연결한다.
2. DFR1026을 켜고 패드 6/5 또는 USB-A 출력에서 5 V와 극성을 확인한다.
3. 5 V가 아니거나 비정상 발열·LED 이상이 있으면 즉시 분리한다.

### K230D-Zero 전체 기능 시험

1. USB 전력계를 DFR1026 출력과 K230D-Zero 사이에 넣는다.
2. 부팅 뒤 OV5647, SSD1306, Wi-Fi 웹서버, UDP 마우스, AI 손 추적을 모두 켠다.
3. 완충 상태와 보호 차단 직전 상태에서 각각 10분 이상 시험한다.
4. 합격 기준은 USB-C 입력 전압 **4.75 V 이상**, 배터리 전류 **1.8 A 이하**, 재부팅·Wi-Fi 끊김·보호 차단 없음, 비정상 발열·냄새·팽창 없음이다.
5. 하나라도 실패하면 사용을 멈추고 이 조합을 A 등급으로 승격하지 않는다.

## 9. 증상별 대응

| 증상 | 즉시 조치 | 가능한 원인 |
| --- | --- | --- |
| 충전전류가 0.78 A 초과 | 전원·배터리를 분리 | RPROG 값/납땜 오류, 다른 PCB 리비전 |
| TP4056 또는 배터리가 과열 | 충전 중지, 불연성 장소로 이동 | 선형 충전 발열, 단락, 손상 셀 |
| K230 재부팅·Wi-Fi 끊김 | 전원 분리 | 순간 부하, 출력 전압 강하, 접촉 불량 |
| 출력이 5 V가 아님 | K230 연결 금지 | OUT/GND 오결선, DFR1026 불량, 배터리 저전압 |
| 커넥터·리드가 따뜻함 | 즉시 사용 중지 | 정격 초과 또는 접촉 저항 증가 |
| 배터리 팽창·피복 손상·냄새 | 충전·사용 금지 | 셀 손상; 재사용하지 않음 |

## 10. 금지 사항

- 배터리 셀 탭이나 보호회로에 직접 납땜하지 않는다.
- 53047-0210 PCB 헤더를 전선에 공중 납땜해 배터리 하네스로 쓰지 않는다.
- DFR1026 `VIN`을 TP4056 또는 충전기와 연결하지 않는다.
- TP4056 충전 중 DFR1026·K230D-Zero를 병렬 연결하지 않는다.
- USB-C 플러그에 VBUS/GND 전선을 직접 납땜하거나, CC 구성이 검증되지 않은 USB-C 브레이크아웃을 출력으로 쓰지 않는다.
- 충전 중 방치하거나, 배터리를 안경 다리에 압착·피부에 직접 접촉시키지 않는다.
- 모든 기능 시험 전에는 시연·착용을 하지 않는다.
